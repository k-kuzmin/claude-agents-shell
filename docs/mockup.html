Claude Agents Shell

Статичный макет по фактическому интерфейсу: панель проектов слева, вкладки-сессии выбранного проекта и терминал справа. Действия живут на строке проекта: плюс открывает новую сессию, часы со стрелкой — историю сессий этого проекта. Полоса вкладок показывает только вкладки выбранного проекта; счётчик «ждёт ввода» считает все проекты.

Главное окно

Строка kassa — выбранный проект (акцентная полоса слева), storefront — под курсором: вместо маркера и числа сессий видны кнопки «новая сессия» и «история». Точка у проекта — самое важное состояние его вкладок. Внизу — версия приложения. Строка legacy-crm — каталог недоступен.

Панель diff

Ctrl+Shift+D или кнопка diff на вкладке открывают панель поверх терминала этой вкладки; Esc в панели закрывает её. Оглавление ветки против базы, фильтр по пути и по расширениям, свёрнутые сгенерированные и большие файлы, «без пробелов (-w)», выбор рабочего дерева (когда их больше одного), плашка «есть изменения» после правок агента.

Какой из агентов ждёт вас — видно сразу

Несколько сессий Claude Code в одном окне — по проектам, во вкладках, с лампой состояния у каждой. Внутри вкладки настоящий claude, а не свой чат. Только для Windows.

Кто чего ждёт

Пока один агент собирает проект, второй уже просит разрешения, а третий гоняет сабагентов. Лампа на вкладке говорит, кому из них нужны вы, — переключаться в каждую не придётся.

Состояние приходит из хуков Claude Code, а не из догадок по тексту на экране.

  • Работает

    Агент занят.

  • Ждёт ввода

    Агент закончил или просит разрешения на действие.

  • Работа в фоне

    У агента идут свои сабагенты или фоновые задачи — отвечать пока не нужно.

Счётчик «N ждёт ввода» в полосе вкладок: щелчок переключает на следующую такую сессию, повторные щелчки обходят их по кругу.

Маркер на строке проекта показывает, в каком проекте вас ждут.

Окно не в фокусе? Кнопка в панели задач мигает и приходит уведомление Windows «проект · сессия». Щелчок по нему открывает эту вкладку.

Одно окно вместо россыпи терминалов

Слева — проекты с веткой git и числом сессий, справа — вкладки выбранного проекта. Кнопка «+» на строке проекта открывает новую сессию без диалогов: каталог, оболочка и аргументы claude уже прописаны.

Возможности

Вчерашняя сессия — в истории

Кнопка с часами на строке проекта открывает прошлые сессии: имя или первое сообщение, дата, ветка, короткий id. Поиск по имени, первому сообщению и id работает по мере ввода.

Enter продолжает сессию во вкладке, кнопка рядом с id копирует полный id. Сессия, которая уже открыта, помечена «открыта» — выбор переключит на неё, а не запустит второй claude.

Что поменял агент — рядом с терминалом

Ctrl+Shift+D открывает изменения ветки относительно базовой: коммиты, незакоммиченные и новые файлы. Если агент правит файлы при открытой панели, она предлагает обновиться.

Агент может показать всё сам: в сессию подключены инструменты show_diff и show_file. Попросите «покажи, где это написано» — панель откроется с нужными строками. Код подсвечивается в цветах тёмной темы VS.

Вкладки возвращаются

Закрыли окно — при следующем запуске сессии поднимаются в прежнем порядке и продолжаются с тем же контекстом через claude --resume. Вышли командой /exit — сессия не вернётся.

Файлы и скриншоты

Ctrl+V с файлами из проводника вставляет их пути, скриншот из буфера уходит в Claude Code картинкой. Файлы можно и перетащить в терминал.

Настройки проекта

Оболочка — PowerShell 7, Windows PowerShell или cmd, команда перед запуском claude, дополнительные аргументы. Видно, есть ли в каталоге CLAUDE.md и .mcp.json.

Если сессия упала

Вкладка остаётся с кодом выхода и кнопкой «перезапустить».

Чем отличается

От нескольких окон терминала

Одно окно вместо россыпи, состояние каждой сессии видно без переключения на неё, проект помнит свой каталог и аргументы, вчерашняя сессия — в истории.

От веб-интерфейсов и чатов поверх агента

Во вкладке живёт сам claude со своим TUI. Нечему отставать от обновлений Claude Code, и оболочка не может исказить то, что показывает агент.

От Electron-обёрток и IDE

На всё окно — один движок WebView2, новая вкладка — ещё один терминал на той же странице, а не ещё один процесс браузера. Каталоги и процессы не опрашиваются по таймеру.

Сравнительных замеров с другими инструментами не проводилось — это описание устройства, а не цифры.

Установка

  1. Скачайте и запустите

    Архив ClaudeAgentsShell-<версия>-win-x64.zip из последнего релиза: распакуйте и запустите ClaudeAgentsShell.exe. .NET ставить не нужно — сборка самодостаточная.

  2. Проверьте систему

    Windows 10 1809+ или Windows 11 x64 и WebView2 Runtime. В Windows 11 он уже есть; если нет, приложение скажет и даст ссылку.

  3. Установите Claude Code

    В каждой вкладке запускается команда claude, поэтому она должна работать в обычном PowerShell. Проверьте: claude --version.

Приватность

  • В ваш проект ничего не пишется. Настройки хуков и подключение show_diff и show_file передаются сессии через --settings и --mcp-config из каталога приложения.
  • Файлы сессий Claude Code только читаются. В ~/.claude/projects приложение ничего не удаляет и не записывает.
  • Слушает только локальный адрес. Хуки и инструменты приходят на 127.0.0.1.
  • Терминалы не грузят ничего из интернета. xterm.js и highlight.js лежат в приложении, CDN не используются.
  • Вывод агента не анализируется. Состояние вкладки определяется только по хукам.
  • Свои данные приложение хранит в %APPDATA%\ClaudeAgentsShell\.
